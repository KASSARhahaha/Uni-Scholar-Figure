# Journal reference method

Use a published figure as a style reference only after the scientific contract is stable.

## Selecting a reference

Choose one figure that matches all available criteria:

- same target journal or journal family
- similar figure role, such as method overview or schematic-led composite
- similar scientific modality and information density
- accessible source page with a stable citation
- sufficient resolution for visual inspection

If no exact match exists, use the closest disciplinary reference and state the mismatch. Verify the current journal figure guide separately because one published example does not define the submission rules.

## Extract abstract design tokens

Record:

- final aspect ratio and approximate column width
- panel hierarchy and reading direction
- panel-label convention
- background treatment and whitespace
- typography family, relative size, and label density
- palette roles, not exact sampled colors unless the journal specifies them
- connector grammar, arrowhead style, line-weight hierarchy, and corner radius
- how the figure distinguishes inputs, core method, validation, and outputs
- which elements are direct-labeled and which need a legend

Then write an originality statement listing the new figure's independent content, layout changes, iconography, terminology, and palette decisions.

## Default high-impact-journal stance

When the journal is not specified, use a provisional double-column canvas near 180 mm wide, white background, sans-serif text, lowercase bold panel labels, and readable 5 to 7 pt final-size labels. Keep the central method visually dominant. Use neutral grey for context, deep blue for the core method, restrained green for validated outputs, and red only for a documented limitation or failure state.

These values are provisional. Confirm the latest target journal author guide before submission.

## Copyright boundary

Do not trace the reference, reuse its custom icons, copy manuscript-specific arrangement, or imitate a distinctive protected illustration. The reference citation belongs in the design record or slide notes, not as a claim that the new figure reproduces the original.
