# UniScholar Figure Support

## Get help

Report reproducible issues through the
[GitHub issue tracker](https://github.com/KASSARhahaha/Uni-Scholar-Figure/issues).
Include the plugin version, operating system, Codex or PowerPoint version when
relevant, expected behaviour, actual behaviour, and a minimal non-confidential
example.

## Keep reports safe

Do not place API keys, bearer tokens, private manuscripts, unpublished data,
or restricted images in public issues. Redact files first. If an issue cannot
be reported safely in public, open a minimal issue requesting a private
reporting channel without revealing the sensitive material.

## Scope and response expectations

Support covers the open-source repository, installation guidance, reproducible
defects, and documentation corrections. It does not include a service-level
agreement, guaranteed response time, journal acceptance advice, scientific
validation, or a promise that a third-party online provider will be available.

For Codex-directory account, identity-verification, review, or publication
status questions, use the OpenAI Platform support route associated with the
submitting organization.
