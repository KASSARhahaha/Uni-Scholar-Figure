# UniScholar Figure Codex plugin v0.1.0 release notes

**Release date: 2026-09-10**

Initial public-submission candidate for the `unischolar-figure` skills-only
plugin.

## Included

- Evidence-first Figure 1 workflow design for scientific manuscripts and
  proposals.
- A source-aware journal-reference method that permits design analysis but
  prohibits copying a reference figure's scientific expression.
- Bundled FigEdit procedures for editable SVG and PowerPoint export.
- Quality gates for scientific claims, visual review, and native editability.

## Data boundary

Local deterministic scripts work in the user's project location. Online
research and image-generation routes are optional and require the user to
choose or approve them. See the [privacy policy](../privacy.md).

## Known limits

- The plugin does not validate scientific truth or guarantee journal
  acceptance.
- PowerPoint fidelity and editability depend on the source SVG, installed
  dependencies, and the user's Office environment.
- The plugin does not create an exact copy of a published figure.
